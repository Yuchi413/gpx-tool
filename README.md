# ⛰ GPX 軌跡轉圖片

把 GPX 軌跡檔轉成乾淨的路線圖片（PNG）。純前端網頁，單一 `index.html`，不需要伺服器。

🔗 線上使用：https://yuchi413.github.io/gpx-tool/

## 功能

**路線**
- 上傳單一或多個 GPX 檔案
- 多檔時可選擇依位置合併：從最近的端點依序接起，必要時自動反轉方向
- 可選擇每個檔案使用不同顏色，並可在檔案清單中個別改色
- 路線顏色、粗細（滑桿調整）、背景色、透明背景

**檢視與輸出**
- 預覽區可用滑鼠滾輪縮放、拖曳平移、雙擊重設
- 預設上方為北方，可旋轉 0° 到 359°（滑桿或直接輸入數字），指北針會跟著旋轉
- 輸出寬度可選 1200 / 1600 / 2400 / 3200 px，下載為 PNG

**點位**
- 輸入「緯度, 經度」新增點位，可加標籤
- 形狀：實心圓形（預設）、三角形、正方形、水滴型；顏色、大小可調，每個點位可個別修改
- 可吸附到最近的路線位置，讓圖形中心落在路線上
- 標籤靠近圖片邊緣時會自動換邊，不會超出外框

**距離**
- 選擇起點：某個 GPX 檔案的起點，或自訂座標
- 顯示每個點位距起點的沿路線行走距離（公里）
- 可選擇是否在圖上標示起點、是否在標籤附上距離

## 使用方式

1. 開啟網頁，上傳一個或多個 `.gpx` 檔案
2. 在右側預覽確認路線，調整顏色、粗細與旋轉角度
3. 需要的話，輸入座標新增點位，並設定起點以顯示距離
4. 按「下載 PNG」輸出圖片

## 部署到 GitHub Pages

1. 把 `index.html` 上傳到 repository 根目錄
2. 到 **Settings → Pages**，Source 選 **Deploy from a branch**，Branch 選 `main`，資料夾選 `/ (root)`
3. 儲存後等待一兩分鐘，網站即可使用

## 注意事項

- 所有處理都在瀏覽器內完成，GPX 檔案不會上傳到任何伺服器
- 圖片不含底圖，只有軌跡與點位
- 距離為沿路線累加的水平距離，不含高低起伏
- 不合併而有多條路線時，只有和起點在同一條路線上的點位才會顯示距離
- 更新網站後若畫面沒變，請強制重新整理（Ctrl+Shift+R）清除快取
