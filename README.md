# ⛰ GPX 軌跡轉圖片

把 GPX 軌跡檔轉成乾淨的路線圖片或海報。
🔗 線上使用：https://yuchi413.github.io/gpx-tool/

## 功能

### 路線
- 上傳單一或多個 GPX 檔案
- 多檔時可依位置合併：從最近的端點依序接起，必要時自動反轉方向
- 可讓每個檔案使用不同顏色，並在檔案清單中個別改色
- 路線顏色、粗細（滑桿調整）、背景色、透明背景

### 圖片大小與方向
- 預設模式：圖片比例依軌跡範圍自動決定，輸出寬度可選 1200 / 1600 / 2400 / 3200 px
- 自訂尺寸：輸入寬和高（100 到 6000 px），軌跡等比縮放並置中
- 與底圖相同：使用底圖照片的尺寸
- 預設上方為北方，可旋轉 0° 到 359°（滑桿或直接輸入數字），指北針會跟著旋轉

### 標題與文字
- 可選擇加上海報風格的標題與資訊欄，放在圖片上方或下方，內容包含路線名稱、日期、距離、爬升與下降
- 上傳 GPX 時會自動帶入檔名與 GPX 內記錄的日期，可自行修改
- 圖上文字字體可選黑體、明體、楷體、圓體、等寬（實際顯示取決於裝置是否安裝該字體）

### 底圖照片
- 可選擇照片作為整張圖片的背景
- 可調整照片的透明度與暗度，也可一鍵移除
- 圖上文字顏色會依照片亮度自動切換深淺

### 統計與剖面圖
- 圖上顯示總距離、累積爬升、累積下降、最高點
- 路線下方可附高度剖面圖，新增的點位與起點會標在海拔曲線上
- 爬升與下降會先平滑處理，並忽略 3 公尺內的起伏
- 需要 GPX 內含海拔資料；沒有海拔時只顯示距離

### 點位
- 輸入「緯度, 經度」新增點位，可加標籤
- 形狀：實心圓形（預設）、三角形、正方形、水滴型；顏色、大小可調，每個點位可個別修改
- 標籤位置可選自動、右、左、上、下，可設定預設值，也可逐點調整
- 可吸附到最近的路線位置，讓圖形中心落在路線上
- 批次匯入：一次貼上多行座標（格式：緯度, 經度, 標籤），或匯入 CSV 檔
- 點位清單可展開查看完整資料：座標、路線上最近位置、距起點距離、海拔、形狀、顏色、大小、標籤位置

### 起點與距離
- 選擇起點：某個 GPX 檔案的起點，或自訂座標
- 顯示每個點位距起點的沿路線行走距離（公里）
- 可選擇是否在圖上標示起點、是否在標籤附上距離

### 預覽與輸出
- 預覽區可用滑鼠滾輪或雙指縮放、拖曳平移、雙擊重設檢視
- 版面會依電腦、平板、手機自動調整；預覽區固定不動，捲動設定面板時仍看得到
- 設定面板可收合，預設只展開上傳區塊
- 輸出格式：
  - **PNG**：點陣圖，支援透明背景
  - **SVG**：向量圖，放大不失真，可用 Illustrator、Inkscape 編輯
  - **PDF**：依圖片比例自動選 A4 直式或橫式，內容為高解析度圖片

## 使用方式

1. 開啟網頁，上傳一個或多個 `.gpx` 檔案
2. 在預覽確認路線，調整顏色、粗細、方向與圖片大小
3. 需要的話，加上標題、底圖照片、統計與剖面圖
4. 輸入座標或批次匯入新增點位，並設定起點以顯示距離
5. 選擇輸出格式，按「下載」

## 批次匯入格式

每行一個點位，座標在前、標籤在後，以逗號、分號或空白分隔：

```
25.0330, 121.5654, 台北101
24.1477, 120.6736, 台中車站
```

標籤放在座標前面也能辨識；標題列或格式不對的行會自動略過。CSV 請存成 UTF-8，否則中文標籤可能亂碼。

## 部署到 GitHub Pages

1. 把 `index.html` 上傳到 repository 根目錄
2. 到 **Settings → Pages**，Source 選 **Deploy from a branch**，Branch 選 `main`，資料夾選 `/ (root)`
3. 儲存後等待一兩分鐘，網站即可使用

更新網站時，把新的檔案同樣命名為 `index.html`，在 repo 用 **Add file → Upload files** 覆蓋上傳。若畫面沒有變化，請強制重新整理（Ctrl+Shift+R）清除快取。

## 注意事項

- 所有處理都在瀏覽器內完成，GPX 檔案與照片不會上傳到任何伺服器
- 圖片不含地圖底圖，只有軌跡與點位；需要底圖時可使用自己的照片
- 距離為沿路線累加的水平距離，不含高低起伏
- 不合併而有多條路線時，只有和起點在同一條路線上的點位才會顯示距離
- 固定圖片尺寸過小，放不下標題、統計列與剖面圖時，圖片高度會自動略為加高
- 超過長邊 2400px 的照片會先縮小再使用；SVG 會把照片嵌入檔案，所以檔案會比較大
- SVG 內的文字使用系統字體，在別的電腦上開啟時字體可能略有不同
